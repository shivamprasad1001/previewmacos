## Reporting a Vulnerability

We take the security of Preview seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please send an email to:
- **Shivam Prasad**: [shivamprasad1001@gmail.com](mailto:shivamprasad1001@gmail.com)
- **TriviLabs Security**: [security@trivilabs.in](mailto:hello@trivilabs.in)

Please include:
1. Description of the vulnerability and its potential impact.
2. Steps to reproduce or proof-of-concept document/payload.
3. Your operating system and Preview version.

We will acknowledge receipt within 48 hours and work on a fix promptly.
