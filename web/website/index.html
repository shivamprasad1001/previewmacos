From Source (Any OS)

Python 3.10+ with virtual environment

github.com/shivamprasad1001/previewmacos

Clone, install, and launch 
git clone https://github.com/shivamprasad1001/previewmacos.git
cd previewmacos
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./run.sh
Build .deb from source 
chmod +x build_deb.sh && ./build_deb.sh
sudo dpkg -i dist/preview-app_*.deb

Frequently Asked Questions

Is it free?

Yes. Preview (macOS Edition) is free and open-source software released under the MIT License.

Does it edit PDFs permanently?

Yes, when you save or export. Saving writes annotations (pen, highlighter, shapes, text, sticky notes, signatures, and redactions) and page rotations or reorderings into the output file. Use Save As (Ctrl + Shift + S) if you want to keep an unmodified copy.

Does it work offline?

Yes. All PDF rendering, image loading, markup, signing, redaction, color adjustments, and exporting run locally on your machine. Network access is only used when checking GitHub Releases for app updates.

Is redaction secure?

For PDF documents, Preview uses PyMuPDF's permanent redaction engine (apply_redactions()) to strip underlying text and graphics inside the redacted area before saving. Always verify the exported output when handling sensitive files.

Which Linux distros are supported?

Prebuilt .deb packages target Ubuntu, Debian, Kali Linux, Linux Mint, and other Debian derivatives on amd64. Any other Linux distribution can run the app from source with Python 3.10+.

How do I update?

Preview includes a Sparkle-style in-app updater that checks GitHub Releases automatically or from the application menu, downloads the new package, and runs the native installer (dpkg via pkexec on Linux, silent installer on Windows). You can also download the latest release manually from GitHub.

How do I report a bug?

Open an issue using the Bug Report template on GitHub. For security vulnerabilities, follow SECURITY.md instead of opening a public issue.
